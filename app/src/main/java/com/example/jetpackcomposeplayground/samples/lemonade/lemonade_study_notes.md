# Lemonade Uygulaması - Çalışma ve Öğrenme Notları

## Proje Amacı
Bir state makinesi (State Machine) mantığı kurarak kullanıcı etkileşimleriyle ekranın adım adım nasıl değiştiğini (`when` blokları) anlamak.

## Temel Öğrenilenler
- Adım bazlı state yönetimi (Limon seçme, sıkma, içme, bardak).
- `clickable` modifier ile dokunma olaylarını yakalama.
- Koşullu (conditional) UI render etme.
