# Order History - Çalışma ve Öğrenme Notları

## Proje Amacı
Gelişmiş liste filtreleme, öğe genişletme (expandable items) ve sipariş geçmişi kartları tasarlamak.

## Temel Öğrenilenler
- Kart tıklamasıyla detay açma/kapama state yönetimi.
- Liste filtreleme ve sıralama mantığı.
- Gelişmiş Material 3 kart yerleşimleri.
