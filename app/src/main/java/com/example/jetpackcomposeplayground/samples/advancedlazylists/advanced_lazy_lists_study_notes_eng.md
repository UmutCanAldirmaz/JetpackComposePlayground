# Unit 3: Advanced Lazy Lists - Study and Technical Notes

## Summary and Concepts

The Advanced Lazy Lists application demonstrates nesting a horizontal filter bar (`LazyRow`) with vertical scrollable lists (`LazyColumn`).

### 1. Horizontal Filter Bar (`LazyRow`)
- A filterable horizontal menu structure using `LazyRow` and `FilterChip` to filter items by category.

### 2. Multi-Component Integrated List Layout
- Combining Header (Report Title), `items()` (Transaction Records), and Footer (Report End) components into a single performant list within a single `LazyColumn`.
