# Lazy Grid Practice - Çalışma ve Öğrenme Notları

## Proje Amacı
`LazyVerticalGrid` kullanarak öğeleri sütunlar halinde ızgara (grid) yapısında verimli bir şekilde listelemek.

## Temel Öğrenilenler
- `GridCells.Adaptive` ve `GridCells.Fixed` ile sütun yönetimi.
- `LazyVerticalGrid` ve `items` kullanımı.
- Izgara elemanları arası boşluk (`horizontalArrangement`, `verticalArrangement`) ayarları.
