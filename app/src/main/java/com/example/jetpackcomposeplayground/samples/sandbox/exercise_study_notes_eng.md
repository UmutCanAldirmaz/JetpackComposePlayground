# Exercise Sandbox & Lab - Study and Technical Notes

## Summary and Concepts

The Exercise Sandbox area serves as an experimental laboratory environment to freely test Jetpack Compose components, custom layouts, state experiments, and interactive UI fragments.

### 1. Layered UI Experiments
- Combining fundamental Compose building blocks such as `Card`, `Column`, `Row`, `Button`, `Slider`, and `Checkbox`.
- Opportunity to quickly test real-time state mutations (`remember { mutableStateOf(...) }`).
